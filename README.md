# resimpletext

A project I'm making for fun about markdown files. For now it's an markdown
viewer, but, I'm planning to add text editing capabilities. It's in a really
early stage.

# Dependencies

- python 3.14.7
- tkinter
- tk 8.6
- tkinterweb

# How to use?

Clone the repo and run the "main.py" script with the python interpreter:

```
git clone git@github.com:SimonDeSchriewa/resimpletext.git
cd resimpletext
```

Running:
```
python main.py
```
